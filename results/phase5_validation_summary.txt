8. THRESHOLD ANALYSIS FINDINGS
   -----------------------------
   Thresholds analysed on the test set (production threshold
   NOT changed - analysis only):
 Threshold  Precision  Recall     F1  Accuracy
       0.3     0.5446  1.0000 0.7052    0.5446
       0.4     0.5455  0.9961 0.7049    0.5459
       0.5     0.5679  0.8346 0.6759    0.5641
       0.6     0.6503  0.1881 0.2918    0.5028
       0.7     0.6000  0.0006 0.0011    0.4555

   Best observed threshold by F1: 0.31 (F1 = 0.7052)
   Lower threshold -> higher recall (catch more placed students),
   higher false positives (false hope). The choice is a policy
   decision, not a model decision.
   Note: the low optimal threshold reflects the model's weak separation (ROC-AUC 0.578);
   at 0.30-0.40 almost every student is predicted placed
   (recall ~1.0), which is of little practical value.

9. CALIBRATION FINDINGS
   ---------------------
   Brier score: 0.2435 (lower is better; 0 = perfect)
   Brier of constant base-rate predictor: 0.2480
   Improvement over base rate: 0.0045
   The predicted probabilities are only marginally better than
   the constant base rate - treat them as ranking scores, not
   exact likelihoods.

10. LEAKAGE FINDINGS
    -----------------
    ✅ No data leakage found (see results/phase5_leakage_check.txt)
       - salary_package_lpa and student_id are excluded
       - feature engineering fitted on training data only
       - the Phase 4 academic_skill_index fix is in effect

11. OVERFITTING FINDINGS
    ----------------------
    Potential overfitting flagged: max gap 0.1511, avg gap 0.0823.
    Train metrics exceed test metrics; see section 6 above.

12. FINAL CONCLUSION
    ----------------
    The Phase 4 RandomForestClassifier model achieves an
    ROC-AUC of 0.5777 on the untouched test set with a
    focus on recall (catching genuinely placed students). The
    features in this dataset carry limited predictive signal
    (AUC ~0.58), so the model should be used as a screening /
    counselling aid, not as a definitive placement oracle.
    Validation found no data leakage and no severe overfitting;
    the CV and test-set numbers are consistent.

    Reported honestly - results were not artificially inflated.
